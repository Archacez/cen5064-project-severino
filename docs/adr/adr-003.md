# ADR-003: Select Streamlit for the Web-Based GUI

**Date:** 2026-11-15 **Status:** accepted

## Context

Budgeter currently uses a command-line interface, but the project needs a web-based GUI that supports CRUD operations and a dashboard with graphs and charts. 
The project is primarily written in Python, and the existing layered architecture should be preserved. Development time and minimizing additional technologies are important constraints.

## Decision

Use Streamlit as the presentation framework for Budgeter's web-based GUI. The Streamlit interface will communicate with the existing service layer, reusing the application's domain logic and repositories.

## Consequences

Streamlit provides built-in components for forms, tables, and charts, allowing the GUI to be developed using Python without introducing a separate frontend framework. 
This reduces development complexity and allows the existing architecture to be reused. However, Streamlit offers less frontend customization than frameworks such as React. 
This decision may be revisited if the project requires more complex frontend interactions or customization.
